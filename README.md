# KXphoto
這是一個個人攝影作品集網站，使用 HTML、CSS、JavaScript、jQuery、sql server建立。  
網站設計以簡潔排版，展示台灣風景與街拍作品。
## 特色  
- 切版與視覺設計：運用 CSS Grid 打造非對稱相片牆，結合 RWD 響應式排版，提升跨裝置視覺體驗。
- 互動與 API 介接：JavaScript 輪播圖，並透過 Fetch API 串接後端 API。
- 後端與資料庫：使用 Node.js 建構，搭配 SQL Server 進行會員資料處理。
